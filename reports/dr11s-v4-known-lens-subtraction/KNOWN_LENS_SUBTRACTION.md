# Subtracting the Known-Lens Catalogs from the ClaudeNet v4 DR11-South Candidate Ranking

**Internal data-product note — agentic-lensing program (X. Huang group)**
**Author:** Greg Benson (with an adversarial multi-agent verification workflow) · **Date:** 2026-07-10
**Repo:** `agentic-lensing` · **Script:** `reproductions/claudenet/397_remove_known_lenses.py`

> **Provenance.** The subtraction was performed by a single deterministic script (`397`), then
> verified three ways: (1) every one of the 150,000 sky separations was recomputed with a second,
> independent matcher (`sklearn.neighbors.BallTree(metric="haversine")` vs astropy
> `match_to_catalog_sky`) — they agree to 1.8 × 10⁻¹⁰ arcsec with zero disagreements about which
> catalog entry is nearest; (2) the written CSVs were re-checked against the inputs by a suite of
> post-hoc integrity assertions, and the product was regenerated byte-identically by a bare
> invocation of the committed script; (3) the script was put through a four-lens adversarial code
> review, each finding handed to a separate agent instructed to *refute* it. The two real defects
> found were in the `--flag-only` diagnostic path, both fixed, neither affecting the shipped CSV.

## What this document is for

`dr11s_v4_candidates_150k_noknown.csv` is a ranked list of **145,856 DESI Legacy Survey
DR11-south sources** — the **full ClaudeNet v4 top-150k, with published lenses removed** —
intended for sharing outside the immediate group. This note records exactly how it was produced
and what it does and does not claim.

> **Read this first.** This is a *ranked shortlist for inspection*, not a lens sample. The score
> it is ranked by is **not a calibrated lens probability**, and no visual or model-based vetting
> has been applied. The overwhelming majority of these 145,856 sources are **not** strong lenses.
> See [Qualifications](#qualifications).

> **This supersedes an earlier 131,336-row cut.** The first version
> (`dr11s_v4_new_candidates_noknown.csv`, no longer shipped) kept only the 134,078 candidates *new
> relative to our previous sweep*, which discarded 14,520 real candidates — including v4's
> **#1-ranked** source (`s_276631_313`, `mean5` 0.708). That "new" filter came from the paper,
> where **134,078 net-new** is a sound *novelty* statistic for the re-sweep; it was the wrong cut
> for a *shareable candidate list*, because the previous, lower-recall selector overlapped v4
> most heavily at the very top of the ranking. This list keeps the whole top-150k and carries an
> `is_new` flag instead of filtering on it; the old view is exactly its `is_new == 1` survivors.

A copy of this note travels with the data as
`reproductions/claudenet/data/v3/dr11s_v4_candidates_150k_noknown.README.md`.

## How it was made

### 1. The v4 ensemble sweep → top 150,000 (`395_combine_resweep.py`, on Perlmutter)

All **53.8 M** DR11-south parent rows are scored by five models, and `mean5` is their plain
arithmetic mean: `member_effnet_B`, `member_zoobot_N` (anchors from the original stage-1 ensemble)
plus three DR11 fine-tuned members `member_effnet_S2_b50_dr11`, `member_effnet_B3_b50_dr11`,
`member_resnet46_C_b50_dr11`. The top 150,000 by `mean5` are kept → `survivors_dr11s_v4.parquet`,
exported to `dr11s_v4_candidates_150k.csv` by `396_export_v4_new_candidates.py --full`, which tags
each row with `is_new`: **134,078** new relative to the previous union-95k sweep
(`survivors_dr10_recal.parquet`, held-out recall 0.54/0.32) and **15,922** also surfaced by it.

`is_new` is **metadata, not a filter.** "New" there means *not previously surfaced by our own,
weaker selector* — not *not a published lens*, and not *examined* (the 15,922 were never vetted
either; the as-run DR11-south vetting used a different model, `v3blend8`). We keep the whole
top-150k.

### 2. Subtract the literature → 145,856 (`397_remove_known_lenses.py`, this step)

Every candidate within **5″** of a known lens is removed. "Known" is the **union of all three
known-lens catalogs this repo ships** — 12,555 rows: KLC (12,210; 4,090 removals), huang2020 (342;
51 removals), external (3; 3 removals).

```
150,000  full v4 top-150k
 −4,144  within 5" of a known lens
────────
145,856  survivors
```

Matching uses astropy `match_to_catalog_sky` (true great-circle separation, so RA wraparound and
the poles are handled), at the 5″ radius this repo already uses in `163_crossmatch_known.py`.

**Removal uses the forward nearest neighbour** (candidate → nearest catalog entry). This is exact,
not an approximation: if a candidate's *nearest* entry lies beyond 5″, then no entry is within 5″,
so a radius search would drop the same rows.

The 4,144 removed rows are **3,724** distinct catalog entries (each some removed row's nearest
match) **+ 420** extra Tractor deblends of **379** of those systems, all removed. Separately,
**3,874** catalog entries lie within 5″ of ≥1 candidate; the difference is duplicate literature
rows for a lens matched via its twin. Matches are tight — median separation **0.13″**, and 3,554
of 4,144 are under 1″.

### Reproduce

```bash
cd reproductions/claudenet
python 397_remove_known_lenses.py                     # full union -> the shipped 145,856-row product
python 397_remove_known_lenses.py --radius 3          # sensitivity
python 397_remove_known_lenses.py --no-default-extra  # KLC only (one huang2020 lens leaks back)
```

The repo's own catalogs are auto-unioned by default, so a bare invocation regenerates exactly the
shipped CSV — verified byte-for-byte. Step 1 requires Perlmutter (`survivors_dr11s_v4.parquet`,
53.8 M parent rows); step 2 runs locally in seconds.

## Verification performed

- **Two independent matchers agree** on all 150,000 separations to 1.8 × 10⁻¹⁰ arcsec, zero
  nearest-neighbour disagreements.
- **Exact partition.** survivors (145,856) + removed (4,144) = input (150,000); disjoint `row_id`
  sets whose union is the input; survivor rows byte-identical to their source rows.
- **Invariant enforced at runtime.** No survivor within 5″ of any catalog entry (nearest 5.0001″);
  every removed row within 5″.
- **Superset check.** The earlier 131,336-row list is exactly the `is_new==1` survivors here, and
  every one of its rows is present — switching to the full list loses nothing.
- **Bare-invocation reproducibility.** The committed script with no arguments regenerates the
  product and audit CSVs byte-for-byte.
- **Audit trail.** Each removed row carries `sep_arcsec` + matched `klc_index`/`klc_ra`/`klc_dec`/
  `klc_ref`/`klc_catalog`.

## Qualifications

**1. `mean5` is a ranking score, not P(lens). This list is *unpublished*, not *pure*.**
Not calibrated to the survey base rate; graded `p_lens` comes only from LensJudge vetting, **not
run on this set**. For scale: **81 of v4's top 100** rows are already-published lenses, falling to
~1 % by rank 20,000 — a ~29× enrichment of the top-100 over the list-wide base rate (2.8 %), and
good evidence the ranking carries real signal. Treat the list as a ranked inspection queue.

**2. "Known" means every catalog *this repo holds*, not every catalog that exists.**
The union covers the KLC, huang2020 and external. `_clib.known_lens_catalogs()` also names
`storfer2024`, `inchausti2025` and `huang2021` published catalogs, **not staged in this checkout**,
so they could not be unioned in. The KLC carries `Storfer 2023` (1,892) and `Huang 2022` (1,301)
refs, so their content is very likely covered — not verified entry-by-entry. A lens published
elsewhere, or after the KLC was compiled, can still be here.

**3. The ~31 % "known-lens recall" in the JSON report is a rough number, not v4's recall.**
3,874 of 12,555 union entries fall within 5″ of a candidate. The denominator is the whole-sky
union (northern + non-DESI entries this DR11-**south** sweep never looked at) and is not deduped.
Cite the paper's held-out figures (Inchausti grade-A 0.87, Storfer 0.825) for recall. This number
is *higher* than the earlier list's (~20 %) precisely because this list keeps v4's lens-rich top.

**4. Sources, not systems.** Deblending means a lens can appear as several `row_id`s; 420 extra
removals on 379 systems handle this on the removal side, but the 145,856 survivors are **sources**,
so the distinct-object count is somewhat lower.

**5. The 5″ radius barely changes the result.** 3,554 @ 1″ · **4,144 @ 5″** · 4,716 @ 30″: only
572 further rows match between 5″ and 30″ (36× the area), so the chance background is low and 5″
sits on a plateau. Full table in the JSON report.

**6. Footprint.** DR11 **south** only (DEC −89.1° to +35.6°). Catalog entries outside it cannot
match by construction.
