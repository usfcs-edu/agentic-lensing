**Internal data-product note — agentic-lensing program (X. Huang group)**
**Author:** Greg Benson (with an adversarial multi-agent verification workflow) · **Date:** 2026-07-13
**Repo:** `agentic-lensing` · **Script:** `reproductions/claudenet/397_remove_known_lenses.py`

> **Provenance.** The subtraction was performed by a single deterministic script (`397`), then
> verified: (1) every one of the 150,000 sky separations was recomputed with a second, independent
> matcher (`sklearn.neighbors.BallTree(metric="haversine")` vs astropy `match_to_catalog_sky`) —
> agreement to 1.8 × 10⁻¹⁰ arcsec, zero nearest-neighbour disagreements; (2) integrity assertions

> committed script; (4) **all four Huang-group DESI searches cross-matched against the shipped
> list to confirm none survive.**

## What this document is for

`dr11s_v4_candidates_150k_noknown.csv` is a ranked list of **145,297 DESI Legacy Survey DR11-south
sources** — the **full ClaudeNet v4 top-150k, with published lenses removed** — for sharing outside
the immediate group. This note records how it was produced and what it does and does not claim.

> **Read this first.** This is a *ranked shortlist for inspection*, not a lens sample. The score
> it is ranked by is **not a calibrated lens probability**, and no visual or model-based vetting
> has been applied. The overwhelming majority of these 145,297 sources are **not** strong lenses.
> See [Qualifications](#qualifications).

> **Revision history.**
> - *2026-07-09* — first cut (131,336 rows), restricted to the 134,078 new-vs-previous-sweep subset.
> - *2026-07-10* — ship the full top-150k minus known lenses (145,856), carrying `is_new` as
>   metadata rather than filtering on it; the 131,336 restriction had dropped 14,520 real
>   candidates including v4's #1-ranked source.
> - *2026-07-13* — **close the Inchausti+2025 gap.** The removal set had been KLC + Huang+2020 +
>   external. The KLC does **not** contain the group's DR10 search (Inchausti+2025) at all — 0 of
>   811 entries — so **559 published Inchausti lenses had survived**. This revision unions all four
>   group DESI searches; the product drops to 145,297.

A copy of this note travels with the data as
`reproductions/claudenet/data/v3/dr11s_v4_candidates_150k_noknown.README.md`.

## How it was made

### 1. The v4 ensemble sweep → top 150,000 (`395_combine_resweep.py`, on Perlmutter)

All **53.8 M** DR11-south parent rows scored by five models; `mean5` = their arithmetic mean
(`member_effnet_B`, `member_zoobot_N` + three DR11 fine-tuned members). Top 150,000 →
`survivors_dr11s_v4.parquet`, exported by `396 --full` to `dr11s_v4_candidates_150k.csv` with an
`is_new` flag. `is_new` is **metadata, not a filter** — we keep the whole top-150k.

### 2. Subtract the literature → 145,297 (`397_remove_known_lenses.py`)

Every candidate within **5″** of a known lens is removed. "Known" = the **union of all six catalogs
this repo ships** (16,573 rows), covering the group's four DESI searches:

| Catalog | Rows | In KLC (5″) | Removed (nearest-attributed) |
|---|---:|---:|---:|
| KLC (`klc_clean250629ymh.csv`) | 12,210 | — | 3,004 |
| Storfer+2024 (DR9) | 1,895 | 1,895 (100 %) | 613 |
| Huang+2021 (DR8) | 1,312 | 1,312 (100 %) | 475 |
| **Inchausti+2025 (DR10)** | 811 | **0 (0 %)** | **559** |
| Huang+2020 (DR7) | 342 | 335 (98 %) | 49 |
| external | 3 | — | 3 |

```
150,000  full v4 top-150k
 −4,703  within 5" of a known lens
────────
145,297  survivors
```

**Attribution ≠ contribution.** The per-catalog column is which catalog is a row's *nearest*
match, not which is *responsible*. Storfer+2024 (613) and Huang+2021 (475) are fully inside the
KLC, so those rows were already removed via the KLC in the previous (145,856) revision — they only
re-attribute to the nearer group catalog now. The **only net-new removals** over the previous 4,144
are the **559 Inchausti+2025** rows, the one search absent from the KLC.

Matching: astropy `match_to_catalog_sky`, forward nearest neighbour, 5″ (the `163` convention).
Exact for removal — if a candidate's nearest entry is beyond 5″, none is within 5″. The 4,703
removed rows are **4,250** distinct catalog entries + **453** extra Tractor deblends of **409**
systems; median separation **0.11″**, 4,076 of 4,703 under 1″.

### Reproduce

```bash
cd reproductions/claudenet
python 397_remove_known_lenses.py                     # full union -> the shipped 145,297-row product
python 397_remove_known_lenses.py --radius 3          # sensitivity
python 397_remove_known_lenses.py --no-default-extra  # KLC only (huang2020 + 559 inchausti leak back)
```

A bare invocation regenerates the shipped CSV byte-for-byte. Step 1 needs Perlmutter; step 2 runs
locally in seconds.

## Verification performed

- **Two independent matchers agree** on all 150,000 separations to 1.8 × 10⁻¹⁰ arcsec, zero
  disagreements.
- **Exact partition.** 145,297 + 4,703 = 150,000; disjoint `row_id` sets; survivor rows
  byte-identical to source.
- **Invariant enforced at runtime.** No survivor within 5″ of any catalog entry (nearest 5.0001″);
  0 of the shipped top-100 match a known lens.
- **All four group searches confirmed subtracted.** 0 of Huang+2020/2021, Storfer+2024,
  Inchausti+2025 survive within 5″ of any shipped row.
- **Bare-invocation reproducibility** and a full **audit trail** (`sep_arcsec` + matched
  `klc_*`/`klc_catalog` on every removed row).

## Qualifications

**1. `mean5` is a ranking score, not P(lens). This list is *unpublished*, not *pure*.**
Not calibrated; graded `p_lens` comes only from LensJudge vetting, **not run on this set**. For
scale: **86 of v4's top 100** rows are already-published lenses, against a 3.1 % rate across the
full top-150k — a ~27× enrichment, good evidence the ranking carries real signal. The large
majority of the 145,297 are **not** strong lenses.

**2. "Known" now covers all four group searches, but not every catalog that exists.**
The union covers the KLC + Huang+2020/2021 + Storfer+2024 + Inchausti+2025 + a small external list.
A lens published *outside* these — by another group, or after these were compiled — can still be
here. (This note previously claimed the group searches were "very likely covered via the KLC";
that was wrong for Inchausti+2025, and is now fixed by staging the catalog directly.)

**3. The ~38 % "known-lens recall" in the JSON report is a loose number, not v4's recall.**
6,300 of 16,573 union entries fall within 5″ of a candidate; the denominator is the whole-sky
union and is **not deduped** (a lens in KLC *and* Storfer+2024 *and* Huang+2021 counts three
times — which is why this rose with the added catalogs). Cite the paper's held-out figures
(Inchausti grade-A 0.87, Storfer 0.825).

**4. Sources, not systems.** Deblending: 453 extra removals on 409 systems on the removal side; the
145,297 survivors are **sources**, so the distinct-object count is somewhat lower.

**5. The 5″ radius barely changes the result.** 4,076 @ 1″ · **4,703 @ 5″** · 5,312 @ 30″: only
609 further rows between 5″ and 30″. Full table in the JSON report.

**6. Footprint.** DR11 **south** only (DEC −89.1° to +35.6°).
